# 2026 世界杯预测分析系统第一阶段方案

## 产品定位

第一阶段是个人使用的本地数据分析工作台，用样例数据跑通完整预测闭环。系统不把盘口经验当作最高优先级，而是把它作为市场信号、人工标签和复盘维度，和基础实力、进球模型、赔率、修正因子、校准层共同输出概率与风险。

## 页面与信息架构

- 比赛预测：首屏主视图，展示 2026 赛制下 104 场样例比赛，支持搜索、筛选、排序、风险标记、进入单场分析。
- 单场分析：查看胜平负、比分、进球数、盘口水位走势、标签命中、下注金额与风险输入、复盘记录。
- 小组模拟：展示 12 个小组的预计积分、净胜球、进球、出线概率。
- 淘汰赛路径：展示 32 强到决赛的样例晋级路径与阶段概率。
- 冠军概率：基于模拟结果展示冠军候选、概率、置信区间、模型来源。
- 串关筛选：按价值、置信度、相关性、风险预算筛选组合。
- 复盘校准：记录赛果、赢盘/输盘、冷门分类、标签命中、模型误差。
- 模型版本：记录模型权重、校准参数、样例快照、准确率指标。

## SQLite 数据结构

- `teams`：球队基础实力、Elo/Glicko、进攻防守参数。
- `matches`：104 场比赛槽位、阶段、小组、开球时间、球队或占位符。
- `odds_snapshots`：欧赔、亚盘、大小球、水位、采集时间、来源、快照哈希。
- `predictions`：模型版本、赔率快照、胜平负概率、期望进球、置信度、风险和值。
- `score_probabilities`：比分概率矩阵。
- `goal_probabilities`：总进球概率分布。
- `model_versions`：模型架构、权重、校准参数、准确率摘要。
- `tag_rules`：盘口经验标签的触发条件、影响方向、影响强度、历史命中率。
- `match_tags`：比赛命中的人工/规则标签与复盘结果。
- `results`：比赛胜平负赛果、比分、赢盘/输盘、大小球、冷门定义。
- `reviews`：赛后复盘、错误归因、人工校准记录。
- `import_runs`：样例导入、手动刷新、后续外部数据导入的审计记录。

## 预测模型接口

模型使用分层流水线：

1. 基础实力层：Elo/Glicko 转换成主客基础胜率和攻防强度。
2. 进球模型层：Poisson/Dixon-Coles 生成比分矩阵、总进球分布和胜平负概率。
3. 市场赔率层：欧赔去水、亚盘水位变化、大小球盘口走势转换成市场概率。
4. 修正因子层：伤停首发、赛程体能、天气、舆论、人工经验标签作为低权重修正。
5. 输出校准层：融合概率、置信度、冷门风险、串关价值、复盘校准指标。

第一阶段实现可复现的样例算法，接口和数据形态按后续接入真实数据、回测、训练和临场更新预留。

## 盘口规则引擎

支持标签：楼层、盘口区间、极度拉满、极度回盘、卡区间、妖刀、胜平负结构、中庸结构、小顺结构、大顺结构、热赛返走势。

每个标签保留：

- 触发条件
- 影响方向
- 影响强度
- 历史命中率
- 复盘结果

标签只进入修正因子和复盘分析，不直接覆盖模型输出。系统明确区分比赛胜平负结果与赢盘/输盘结果，冷门定义也拆分为赛果冷门、盘口冷门和模型冷门。

## 数据更新策略

第一阶段：

- 手动刷新接口：重新计算赔率快照、标签和预测快照。
- 样例数据导入：可重复重建 SQLite。
- 可复现快照：相同模型版本和样例种子得到稳定结果。

后续预留：

- 免费公开数据源抓取适配器。
- 免费 API key 适配器。
- CSV/JSON 手动导入。
- 半小时自动更新。
- 临场高频更新。

## UI 风格

界面是高密度中文数据工作台，不做展示页或营销页。视觉基调克制、专业、长期可用：深色应用底、浅色数据面板、细网格、低圆角、清晰语义色。首屏重点突出概率、盘口变化、模型信心、冷门风险和串关价值。

## 第一阶段验收标准

- 本地启动 React/Vite 页面和 SQLite API。
- 生成并展示 104 场样例比赛预测。
- 首页支持搜索、筛选、排序、快速选中比赛。
- 单场面板展示胜平负、比分、进球数、盘口走势、标签和风险输入。
- 小组模拟、淘汰赛路径、冠军概率、串关筛选、复盘校准、模型版本页面有可用样例数据。
- `/api/refresh` 可以手动刷新预测快照。
- `/api/seed` 可以重建样例数据库。
- 构建通过，浏览器中无首屏布局阻塞或主要交互错误。
